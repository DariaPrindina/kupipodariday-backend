# API для сервиса вишлистов КупиПодариДай

### О проекте

Каждый зарегистрированный пользователь может рассказать о том, какой подарок он бы хотел получить, а также скинуться на подарок для другого пользователя, указав сумму, которую готов на это потратить.

**Frontend проекта:** https://github.com/DariaPrindina/kupipodariday-frontend

## Используемые технологии

- Nest.js
- Postgres
- Typescript
- JWT для авторизации

## Функциональность

- Регистрация и авторизация
- Просмотр главной страницы с лентой подарков
- Добавление или изменение подарков
- Просмотр информации о подарке (чужом или своём)
- Просмотр тематических подборок
- Редактирование профиля
- Просмотр профилей и «хотелок» других пользователей
- Поиск пользователей по имени пользователя или почте
- Заявка для желающих скинуться на подарок
- Копирование подарка
